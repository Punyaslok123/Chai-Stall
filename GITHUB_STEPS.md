# Push to GitHub (delete this file before submitting if you like)
1. github.com -> New repository -> Public, no README.
2. In this folder:
   git init && git branch -M main
   git add research.md && git commit -m "added research.md with my problem and person"
   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
   git push -u origin main      # must be within hour 1
3. After each stage: git add . && git commit -m "your own words" && git push
   Suggested commits: sources added / fieldwork + data / script / README / reflection + video link.
4. Save your AI chats as text files in ai-chats/ and commit them.
5. Email the repo link within 24 hours.
